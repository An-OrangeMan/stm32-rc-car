# STM32F103 二轮蓝牙遥控小车

基于 STM32F103C8T6 的二轮差速小车，手机/电脑通过蓝牙串口发送单字节指令遥控。
速度采用编码器闭环 PI 调节，转弯用左右轮差速实现。

> 本项目由一套自平衡小车代码改造而来：已移除 MPU6050 姿态解算、直立平衡环和超声波测距模块，
> 改为纯遥控 + 闭环调速。相关的 `MyCode/`（MPU6050/DMP 驱动）与 `Core/Src/sr04.c` 仍保留在仓库中，
> 但**不参与编译**。

## 硬件

| 部件 | 型号 / 说明 |
|---|---|
| 主控 | STM32F103C8T6（Cortex-M3，72MHz，HSE 8MHz × PLL9） |
| 电机驱动 | H 桥驱动板，每路需 2 根方向线 + 1 路 PWM |
| 电机 | 直流减速电机 ×2，带正交编码器 |
| 蓝牙 | 串口透传模块（HC-05 / HC-06 等），波特率需为 9600 |
| 显示 | SSD1306 OLED 128×64，I2C 接口，从机地址 0x78 |

### 引脚分配

| 功能 | 引脚 | 外设 / 说明 |
|---|---|---|
| 左轮 PWM | PA11 | TIM1_CH4 |
| 左轮方向 | PB12 / PB13 | GPIO 推挽输出 |
| 右轮 PWM | PA8 | TIM1_CH1 |
| 右轮方向 | PB14 / PB15 | GPIO 推挽输出 |
| 左轮编码器 | PA0 / PA1 | TIM2_CH1 / CH2（编码器模式 TI12） |
| 右轮编码器 | PB6 / PB7 | TIM4_CH1 / CH2（编码器模式 TI12） |
| 蓝牙 TX（模块→MCU） | PB10 | USART3_TX |
| 蓝牙 RX（MCU→模块） | PB11 | USART3_RX |
| OLED SCL | PB8 | I2C1_SCL |
| OLED SDA | PB9 | I2C1_SDA |

> ⚠️ 接线时注意蓝牙模块的 **TX 要接 PB11（单片机收）**、**RX 接 PB10**，并且**必须共地**。
> 如果两个轮子转向相反，交换对应电机的两根方向线，或取反 `Core/Src/pid.c` 中该轮编码器的符号。

### 定时器分配

| 定时器 | 配置 | 用途 |
|---|---|---|
| TIM1 | 预分频 0，周期 7199 → **10kHz PWM** | 双路电机调速 |
| TIM2 | 编码器模式 TI12（4 倍频） | 左轮测速 |
| TIM3 | 预分频 71，周期 9999 → **100Hz（10ms）** | 控制周期中断 |
| TIM4 | 编码器模式 TI12（4 倍频） | 右轮测速 |

## 蓝牙指令协议

串口 9600 / 8N1，**发单个字节**即可，无需换行符。

| 字节 | 动作 |
|---|---|
| `0x01` | 前进 |
| `0x05` | 后退 |
| `0x03` | 右转 |
| `0x07` | 左转 |
| `0x00` | 停止 |
| 其它任意字节 | 停止（兜底） |

指令会被**锁存**，收到为止一直保持，不需要持续发送。

> ⚠️ **无失联超时保护**：蓝牙断开时小车会保持最后一个动作继续跑。
> 调试时请注意，必要时发 `0x00` 或直接断电。
> 如需自动停车保护，可在 `Control()` 里加一个计数器，超时未收到新指令就清零目标速度。

## 控制原理

```
蓝牙指令 ──► 目标速度 / 转向 ──► 速度环 PI ──► 差速叠加 ──► 电机
                    ▲                              │
                    └──── 编码器反馈 ◄─────────────┘
```

每 **10ms**（TIM3 中断）执行一次 `Control()`，流程见 `Core/Src/pid.c`：

1. 读取左右编码器计数（右轮镜像安装，取反对齐符号）
2. 按蓝牙指令得到目标速度 `Target_Speed` 与转向量 `Target_turn`
3. 速度环 PI：`误差 = Target_Speed - (左编码器 + 右编码器)`，输出平均 PWM
4. 差速叠加：`左轮 = 输出 - 转向量`，`右轮 = 输出 + 转向量`
5. 限幅后写入 PWM，并设置方向 GPIO

注意速度环是拿**左右编码器之和**做单环调节，所以手拨单个轮子时两个轮子会一起反向推一下，这是正常现象。

## 可调参数

全部集中在 `Core/Src/pid.c` 顶部：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `SPEED_SET` | `60` | 前进/后退目标速度，单位是「左右编码器计数之和 / 10ms」 |
| `TURN_DIFF` | `2500` | 转弯差速偏移（0 ~ 7200），越大转得越急 |
| `Velocity_Kp` | `40.0f` | 速度环比例增益，太小则起步无力 |
| `Velocity_Ki` | `2.0f` | 速度环积分增益，太小则稳态收敛慢 |
| `INTEGRAL_MAX` | `4000` | 积分限幅，防止积分饱和 |
| `PWM_MAX` | `7200` | PWM 上限（对应 100% 占空比） |

**调参思路**

- 想**跑更快**：先调 `SPEED_SET`。
- 改了 `SPEED_SET` 后**起步发肉、追不上目标**：再一起提 `Velocity_Kp` / `Velocity_Ki`。
- **接上 OLED 观察**：第 1、2 行是左右编码器计数，把两者相加即为实际速度，与第 3 行 `Target_S` 对比。
  实际值能稳定贴着目标值，说明闭环正常。
- **来回抖动或嗡嗡响**：增益给大了，往回退。

## OLED 显示内容

| 行 | 内容 |
|---|---|
| 1 | `Encoder_L:` 左轮编码器计数 |
| 2 | `Encoder_R:` 右轮编码器计数 |
| 3 | `Target_S:` 当前目标速度 |
| 4 | `BT:0xXX rx:N` 最近收到的蓝牙字节 / 累计接收字节数 |

调试蓝牙时看第 4 行：`rx` 不增长说明一个字节都没收到（查接线、共地、模块波特率）；
`rx` 在涨但 `BT` 值不对，说明收到了但内容不符（查发送方是否带了换行符等多余字节）。

## 已知事项

- 无失联保护，蓝牙断开后小车不会自动停车。
- `Core/Src/sr04.c`、`Core/Inc/sr04.h`（超声波）与 `MyCode/`（MPU6050/DMP）为平衡车时期的遗留文件，保留但未参与编译。
- `Core/Inc/oled.h` 中的软件模拟 I2C 宏为遗留代码，实际使用的是硬件 I2C1。
- 本项目未附带开源许可证文件。
